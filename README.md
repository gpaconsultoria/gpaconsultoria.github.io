## 🚀 Cómo usar

### Opción 1: Abrir localmente
Simplemente abre el archivo `index.html` en tu navegador.

### Opción 2: Publicar en GitHub Pages (GRATIS)

1. **Crear cuenta en GitHub** (si no tienes): https://github.com

2. **Crear un nuevo repositorio**:
   - Nombre sugerido: `giovannipuentes.github.io`
   - Marcarlo como público

3. **Subir los archivos**:
   - Arrastra los archivos (index.html, styles.css, script.js) al repositorio

4. **Activar GitHub Pages**:
   - Ve a Settings > Pages
   - En "Source" selecciona la rama `main`
   - Guarda

5. **¡Listo!** Tu sitio estará en: `https://giovannipuentes.github.io`
